* Installation

[[https://github.com/DiamondBond/emacs/blob/master/docs/emacsfromsource.org][Emacs build instructions]]. Targets Emacs 31.

Clone this repo:

#+begin_src sh
  $ git clone https://github.com/diamondbond/emacs.git ~/.emacs.d --depth 1
#+end_src

Packages are installed by [[https://github.com/radian-software/straight.el][straight.el]] on first start.

* Layout

- =early-init.el= :: startup tuning, before packages and UI
- =init.el= :: straight.el bootstrap, =globals--*= settings, loads =lisp/=
- =lisp/base.el= :: built-in settings
- =lisp/keybinds.el= :: personal =C-1= prefix map and global keys
- =lisp/packages.el= :: packages
- =lisp/languages.el= :: language modes, tree-sitter, eglot
- =lisp/functions.el= :: personal commands

=bin/check.sh= boots the config in a throwaway terminal Emacs and fails on
init errors or warnings.

** Icons

Icons come from [[https://github.com/rainstormstudio/nerd-icons.el][nerd-icons]], rendered with =SauceCodePro Nerd Font Mono=
(Arch: =ttf-sourcecodepro-nerd=). Any Nerd Font works; set
=nerd-icons-font-family= to change it.

** LSP

IDE features come from the built-in eglot. Install the language servers you
need (e.g. =clangd=, =gopls=, =rust-analyzer=, =typescript-language-server=).
Tree-sitter grammars install themselves on first use.

** Dependencies

Refer to the [[https://github.com/DiamondBond/emacs/blob/master/docs/dependencies.org][Dependencies documentation]].
